基于 dRehmFlight Teensy BETA 1.3 二次开发的变形四旋翼飞控代码。

> 这是一个实验性无人机项目。代码和硬件配置尚未完成完整飞行验证，
> 不保证适用于其他机架、执行器或动力系统。使用风险由使用者自行承担。

## 硬件配置

| 项目 | 配置 |
|---|---|
| 飞控 | Teensy 4.0 |
| IMU | MPU6050，I2C |
| 接收机 | ELRS，SBUS 输出 |
| 飞行电调 | M1～M4，标准 50Hz PWM |
| 轮驱电调 | M5～M6，双向 PWM，1500us 停止 |
| 升降舵机 | S1/S2，Teensy 引脚 6/7 |
| 线性推杆 | 两套，Teensy 引脚 8～11，经 DRV8871 驱动 |
| 控制通道 | CH1～CH7 |

## 主要修改

- 飞行与轮驱电调改为标准 50Hz PWM。
- 上电默认进入轮驱模式，并先执行收臂。
- CH6 低档必须持续确认后才允许进入其他模式。
- 收臂和展臂使用独立时间参数。
- 收臂途中切回飞行时只补回已经缩回的时间。
- CH5 关闭、油门最低且未解锁时，CH7 可用于推杆地面点动。
- CH7 回到中位立即停止当前动作。
- SBUS 链路丢失和通道异常触发失效保护。

## 构建方法

1. 安装 Arduino IDE 2.x。
2. 安装 Teensyduino。
3. 安装 FastLED 等依赖库。
4. 打开：
   `dRehmFlight_Teensy_BETA_1.3/dRehmFlight_Teensy_BETA_1.3.ino`
5. 选择开发板 `Teensy 4.0`。
6. 选择 `Teensy Ports` 中的设备。
7. 编译并上传。

## 已知限制

- 线性推杆仍属于开环时间控制，没有位置反馈。
- 计时不能证明推杆准确到达指定行程。
- 建议增加机械限位和限位开关反馈。
- 部分 PID 参数和执行器行程仍需实机整定。
- 当前代码不能替代飞前检查和硬件保护措施。

## 安全警告

- 首次烧录、接线和参数测试必须拆除螺旋桨。
- 首次执行器测试应使用可快速切断的独立电源。
- 出现异响、卡死、超行程、异常发热或失控时立即断电。
- 不得依赖软件状态代替电源开关、保险丝和机械限位。
